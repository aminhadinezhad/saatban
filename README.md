# سایت معرفی ساعتبان

صفحهٔ معرفی و فروش اشتراک «ساعتبان». این یک پروژهٔ جدا از خود نرم‌افزار نوبت‌دهی است.

ابزارها همان ابزارهای نرم‌افزار اصلی است: Next.js، TypeScript، Tailwind CSS و فونت وزیرمتن.

## اجرا روی کامپیوتر

```
npm install      # فقط بار اول
npm run dev      # http://localhost:3100
```

برای دیدن روی موبایل، گوشی و کامپیوتر باید به یک وای‌فای وصل باشند. نشانی `Network` را که در ترمینال نمایش داده می‌شود در گوشی باز کنید.

## ساخت نسخهٔ نهایی

```
npm run build    # خروجی در پوشه out
npm start        # نمایش همان خروجی روی http://localhost:3100
```

پوشهٔ `out` فقط فایل‌های HTML، CSS، JS و تصویر است. هر هاستی می‌تواند آن را نمایش دهد و به سرور Node نیازی ندارد.

## تغییر محتوا

| چه چیزی | کجا |
|---|---|
| قیمت طرح‌ها، امکانات هر طرح و توضیح زیر قیمت‌ها | `src/content/site.ts` (`PLANS`، `PLAN_FEATURES` و `PRICING_NOTE`) |
| شماره تماس، تلگرام، بله و ساعت پاسخ‌گویی | `src/content/site.ts` (`CONTACT`) |
| سؤال‌های رایج | `src/content/site.ts` (`FAQ`) |
| تصویرهای نرم‌افزار | `public/screens/*.webp` |

**پیش از انتشار، اطلاعات تماس در `CONTACT` را با اطلاعات واقعی خودتان عوض کنید.**
